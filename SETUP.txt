SKY GITHUB PROFILE SETUP

1. Create a PUBLIC GitHub repository named exactly:
   skylynxf1

2. Download/unzip this bundle.

3. Upload these items to the ROOT of that repository:
   README.md
   assets/
   .github/

4. Commit the files.

5. Open the repository's Actions tab.
   Choose "Generate contribution snake".
   Click "Run workflow".

6. Wait for it to finish. It creates an `output` branch containing the snake SVG.

7. Visit https://github.com/skylynxf1 and the profile README should appear.

Folder structure:
skylynxf1/
├── README.md
├── assets/
│   ├── sky-title.png
│   ├── sky-trophy.png
│   ├── sky-coding.png
│   └── sky-matcha.png
└── .github/
    └── workflows/
        └── snake.yml

NOTE:
GitHub README files cannot run arbitrary CSS/JavaScript, so the pixel characters
are static artwork. The contribution snake is the animated part generated by GitHub Actions.
